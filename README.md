# farmaustralia

Tablero dinámico para registrar horas trabajadas en la farm de Chickens Australia.

## Uso

- Abrí `index.html` en tu navegador.
- Cargá ingreso y salida por día.
- El sistema descuenta automáticamente 30 minutos diarios no pagos.
- Podés ajustar horas con deslizador o ingresarlas manualmente.
- El resumen semanal muestra horas totales, salario bruto y salario neto.

Parámetros configurados:

- Sueldo bruto: `30.35 AUD/h`
- Taxes: `15%`
- Sueldo neto: calculado automáticamente como bruto - 15% taxes
